Enterprise SQL Server Health Toolkit

A production-hardened database maintenance suite with a Spring Boot REST API wrapper to automate health management of an enterprise device fleet database. T-SQL stored procedures use Dynamic Management Views (DMVs) for intelligent index maintenance — dynamically executing REBUILD or REORGANIZE based on fragmentation thresholds. Transaction-safe cursor-based batch cleanup prevents transaction log bloat with automatic pre-deletion backups. Automated diagnostic health reporting surfaces top wait statistics, stale statistics, database file sizes, and high-impact missing indexes. Centralised audit logging via MaintenanceAuditLog enforces traceability — capturing execution times, affected rows, system errors, and transaction statuses across all operations.
